# Web Lua & JS Code Editor

ブラウザ上で Lua や JavaScript のコードをリアルタイムに実行・試走できるオンラインエディタです。

## 🚀 主な機能
- **Monaco Editor 搭載**: VS Code 同等の快適なコード入力（行番号・テーマ対応）
- **ブラウザ内 Lua 実行**: Fengari を使用したクライアントサイド実行（`wait()` などの非同期処理にも対応）
- **JavaScript 実行**: ブラウザ上で直接コードをテスト可能
- **Python 実行**: サーバー連携による実行対応
