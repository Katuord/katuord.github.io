使い方と利用可能コマンド

Luaモードでは画面描画・サウンド再生・入力検知機能が利用できます。

コマンド説明例
draw_rect(x, y, w, h, "color") 指定位置に色付き四角形を描画 draw_rect(10, 10, 50, 50, "#00e676")
play_sound(freq, sec) 指定の周波数(Hz)で音を鳴らす play_sound(440, 0.2)
set_bg("color") 全体の背景色を変更する set_bg("#1a0033")
reset_bg() 背景色を初期状態にリセット reset_bg()
clear_canvas() キャンバスの描画内容をクリア clear_canvas()
wait(sec) 指定した秒数だけプログラムを停止 wait(0.5)
get_mouse_x() キャンバス内のマウスX座標を取得 local mx = get_mouse_x()
get_mouse_y() キャンバス内のマウスY座標を取得 local my = get_mouse_y()
is_mouse_down(btn) マウスボタン押下状態 (0:左 1:中 2:右) if is_mouse_down(0) then ... end
is_key_down("key") 指定したキーが押されているか確認 if is_key_down("a") then ... end
get_last_key() 最後に押されたキー名を取得 print(get_last_key())
print(...) 右下のコンソール領域に文字を表示 print("Hello World!")
